# 📡 麦门雷达 Maimen Radar

> **你赚到的麦麦积分，52.4% 已经白白作废了。**
> 这不是估算，是麦当劳 MCP 接口原样返回的数字（2026-10-18 实测快照，仓库内 `fixtures/` 为当日脱敏样例）。

麦当劳的接口会**静默滤掉你用不了的券**，并且不告诉你原因。麦门雷达专门把这段信息补回来：**为什么不能用、什么时候能用、用不上怎么抢救。**

不是又一个"帮你省钱"的助手——它敢说"这张券其实只多省 2 块，别为它专门跑一趟"。

---

## 它解决什么

打开麦当劳 App 的券包，你看到的是 4 张券。到了店里，可能一张都刷不出来。

实测：券包 4 张，`query-store-coupons` 只放行 **1 张**。另外 3 张被静默滤掉，原因分别是星期窗、`enable` 状态、`beTypes` 不匹配当前取餐方式——**接口一个都不解释**。

麦门雷达把每个"不"翻译成一句人话，并给出出路：

| | 官方券包 | 麦门雷达 |
|---|---|---|
| 哪张券要过期 | ✅ 已有「今日到期」标签 | ✅ |
| **为什么这张现在刷不出来** | ❌ 静默滤除 | ✅ 六维判定 + 人话原因 |
| **今天晚些时候能用吗** | ❌ | ✅ 时段条，一眼可读 |
| **用不上能不能救** | ❌ | ✅ 支持转赠的券自动升级为「送人止损」 |
| **这张券到底省了多少** | ❌ 只报"用券价" | ✅ 同时报真实增益 |
| 积分作废了多少 | ❌ 只有月粒度数字 | ✅ 换算成"够换 52 份两件套 ≈ ¥978 的饭" |

```
9.9元中杯冰美式 → 麦咖啡™冰美式中杯
  原价 ¥19 · 菜单现价 ¥11.9 · 用这张券 ¥9.9

  对外宣传「比原价省 ¥9.1」
  实际比菜单现价只多省 ¥2.0
  ⚠️ 聊胜于无：别为它专门跑一趟
```

`原价 − 券价` 是营销数字，`菜单现价 − 券价` 才是你真省到的。所有省钱工具都在报前者，麦门雷达两个都报。

## 三步上手（WorkBuddy 用户看这里）

不需要装任何依赖。全程只做只读查询；写操作（领券）会先报数、等你点头。

### 一句话安装

```bash
git clone https://github.com/Reen-ZZ/maimen-radar.git && cp -r maimen-radar ~/.workbuddy/skills/
```

（Windows 为 `%USERPROFILE%\.workbuddy\skills\`；MCP Token 配置见下文第 2 步。）

### 1. 申请麦当劳 MCP Token（1 分钟）

前往麦当劳 MCP 开放平台 <https://open.mcd.cn/mcp>，手机号登录后进入【控制台】→【激活】→ 同意服务协议 → 复制 Token。

### 2. 配置 MCP 连接

在 WorkBuddy 左侧边栏【专家·技能·连接器】→【连接器】→ 右上角【自定义连接器】→【配置 MCP】中，
填入 [`mcp-config.example.json`](mcp-config.example.json) 的内容，
并把 `${MCD_MCP_TOKEN}` 替换为你的真实 Token，保存后【启用】。

> 🔒 **Token 只存在你本地**：别提交进任何仓库、别贴进 AI 聊天窗口、别发到网上（《麦当劳 MCP 服务规则》第二条 2 款）。

### 3. 开聊

装好后在对话框里直接说「权益账单」即可触发。先试这三句：

| 你说 | 它给 |
|---|---|
| `权益账单` | 券包全景：哪张现在能用、哪张为什么不行、积分作废了多少 |
| `今天吃啥` | 推荐此刻真能刷出来的那张 + 为什么是它 |
| `生成卡片` | 脱敏分享版小票卡片，可直接转发 |

## 第一次用会发生什么

1. **账户级盘点**——券包全景 + 积分作废了多少。不需要门店，装好就能看。
2. **补门店**——读出你的收藏门店让你选一家。「今天吃啥」「这张划算吗」需要它才能回答。
3. **之后每次开口**——先补算这段时间发生了什么，再答你问的那句。

（完整判据与话术见 [`SKILL.md`](SKILL.md)「冷启动引导」，以它为准。）

## 更多问法

| 你说 | 它给 |
|---|---|
| `这张券划算吗` | 原价/现价/麦金卡/券价四档 + 真实增益 |
| `麦旋风那张为什么用不了` | 人话原因 + 换取餐方式能否救 + 能否转赠 |
| `我那些过期积分本来能换啥` | 按元值/积分性价比换算成具体食物份数 |
| `替我领取优惠券` | 先报可领数量等你确认，**你不点头它不动** |
| `绑一下公司那家店` | 读收藏夹或按城市搜索，起别名记住 |
| `最近有啥活动` | 活动日历速览 |

## 目标用户

- **券包里有券但从没用过的人**——大概率就是你
- 有麦当劳会员、每月积分在悄悄过期的打工人
- 想知道"这张券到底值不值"而不是"看起来省多少"的人
- 想拿麦当劳 MCP 写点东西、但不想踩字段坑的开发者

## 能力边界（说清楚它不做什么）

- **不做任何自动化调用**。没有定时任务、没有后台脚本、没有 GitHub Actions。所有动作由你开口触发。依据《麦当劳 MCP 服务规则》第三条 2 款、第六条 2 款——违规会吊销凭证并可能限制会员账号。
- **不自动下单**。写操作先报数、等你明确确认。
- **不联网、不上传**。所有请求只打到 `https://mcp.mcd.cn`。
- **不越权**：只读你会员账户内的券、积分、菜单、活动。
- **不给医疗或营养建议**。热量只做客观展示。

## 开发者与自检（可选，大众用户可跳过）

项目零依赖（Node ≥ 18），克隆后**不需要 `npm install`**。仓库自带脱敏样例 `fixtures/`，没有 Token 也能跑通渲染与校验：

```bash
git clone <本仓库地址> && cd maimen-radar
node src/demo.mjs              # 出上面的权益账单
node src/demo.mjs --share      # 脱敏分享版卡片 → dist/
node src/check.mjs             # 断言：模型判定与官方过滤是否一致
node src/wake.mjs              # 唤醒四步：补算播报 → 四态 → 账单 → 写回 state
node src/preflight.mjs         # 提交前自检：必备文件、密钥泄漏、断链
```

要接真实数据时，把 Token 填进项目根目录的 `.env`（模板见 `.env.example`），然后：

```bash
node tools/probe-mcp.mjs query-my-coupons   # 拉真实券包到 out/（已 gitignore，不入库）
```

> **两条 Token 通道，互不相干**：`.env` 只喂给上面这些项目脚本；WorkBuddy 连接器用的是第 2 步里你自己粘的那份配置。两边各配各的，一边配了另一边不会自动生效。

### 技术要点

| | |
|---|---|
| 单一数据模型 | `src/model.mjs` 是唯一事实来源，两个渲染器都不许碰原始响应 |
| 惰性重放 | `src/state.mjs` 存快照，每次唤醒补算时间差——**没有定时任务却有"一直在盯着"的体验** |
| 七维判定 | 有效期（含生效起始）/ 星期窗 / 时段窗（含跨午夜）/ 当日余量 / 启用态 / 取餐方式 |
| 一致性自检 | `src/check.mjs` 断言模型判定的可用集合 == 官方 `query-store-coupons` 返回集合，券名回退比对兜底 |
| 脱敏在模型层 | `share:true` 时渲染器根本拿不到敏感字段 |
| 零依赖 | 纯 Node ESM + 原生 `fetch`，无构建步骤 |

### 目录

```
SKILL.md                    Skill 本体：触发、四步唤醒、四态、意图路由、边界
MCP_INTEGRATION.md          实际调用记录（含 traceId）、流程图、一致性校验
src/model.mjs               数据模型与四态判定（唯一事实来源）
src/state.mjs               惰性重放：快照、diff、≤3 行播报
src/wake.mjs                唤醒四步可执行入口：补算播报 → 四态 → 账单 → 写回 state
src/render-text.mjs         使用面：单一事实版式
src/render-html.mjs         传播面：小票卡片
src/tone.mjs                麦门语气，按情境分档
src/check.mjs               一致性断言
src/demo.mjs                渲染演示
src/data.mjs                数据源解析：优先 out/，退回 fixtures/
tools/probe-mcp.mjs         只读探针
tools/make-fixtures.mjs     从本地 out/ 生成脱敏样例
references/fields.md        字段实测笔记
fixtures/                   脱敏样例响应（clone 后无需 Token 即可跑通）
```

> `out/`（真实响应，含可核销券码）、`state/`（本地快照）、`dist/`（渲染产物）、`docs/` 均在 `.gitignore` 内，不入库。
